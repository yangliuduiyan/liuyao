# 六爻纳甲排盘助手

一个纯前端的单页小工具：手动摇卦后把六爻填进去，自动整理纳甲装卦信息，供学习者对照研究。
**只做排盘，不作吉凶断言**，解卦完全由使用者依个人所学自行判断。

在线使用：<https://你的用户名.github.io/仓库名/>

## 功能

- 输入六爻（少阳、少阴、老阳、老阴），也支持 6 位数字快速输入（6 老阴 / 7 少阳 / 8 少阴 / 9 老阳，自初爻到上爻）
- 本卦、变卦，卦宫、卦序（八纯、一至五世、游魂、归魂），六冲卦、六合卦
- 世应、六亲、六神、纳甲干支与五行、伏神
- 年月日时干支、月建、日辰、旬空
- 各爻旺衰（旺相休囚死），月建、日辰对各爻的生克合冲，暗动、日破、月破
- 按事类给出默认用神，可手动更改；标出原神、忌神、仇神
- 动爻的回头生克、进退神、化墓、化绝、化合、化冲，及其对用神、世爻的生克
- 复制排盘文本、保存排盘图片

## 使用方法

1. 选择起卦时间（北京时间）。
2. 选择所测之事，必要时手动指定用神。
3. 填入六爻，点击“排盘”。

## 排盘规则

- 体系：京房八宫、世应；纳甲按乾坤震巽坎离艮兑内外卦。
- 六亲：以本卦卦宫五行为“我”，变爻六亲同样按本卦宫计。
- 六神：按日干起，自初爻向上。
- 月建：以节气（“节”）交接时刻为界，不是农历初一。
- 晚子时（23:00–23:59）日柱可在页面中切换为“0 点换日”或“23 点换日”，默认 0 点换日。
- 旺相休囚死：按月建五行，辰戌丑未月土旺。
- 暗动：静爻旺相逢日冲；日破：静爻休囚死逢日冲；月破：爻支被月建冲。
- 伏神：本卦缺某六亲时，取本宫八纯卦同位爻。
- 未做真太阳时校正。

用神取法、旺衰判断等各流派存在差异，本工具只给出通行默认值并标注客观关系，请以自己所学为准。

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可。

```powershell
Start-Process .\index.html
```

## 部署

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
